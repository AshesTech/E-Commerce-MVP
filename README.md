# E-Commerce MVP Backend

Backend for a multi-brand E-Commerce MVP built with **Next.js**.

## Overview

A modular backend designed so that a single application can power multiple brands — differing only in color scheme and logo — with minimal code changes.

## Features

- **Multi-brand support** — swap branding (colors, logo) without touching core logic
- **Single unified app** — serves both Admin (Vendor) and User (Buyer) roles
- **Modular architecture** — clean separation of concerns for scalability

## Tech Stack

- Next.js

## Roles

| Role | Description |
|------|-------------|
| Admin (Vendor) | Manages products, orders, and brand settings |
| User (Buyer) | Browses and purchases products |
